# 🚀 Ataraxia

## La primera wallet hispana diseñada para nuevos usuarios mexicanos que buscan introducirse en el mundo bitcoin sin complicaciones técnicas.

Ataraxia nace con una misión clara:

**Hacer que Bitcoin y la autocustodia sean accesibles para cualquier persona, independientemente de su experiencia técnica.**

Mientras que millones de usuarios encuentran barreras al ingresar al ecosistema Bitcoin debido a conceptos complejos, configuraciones avanzadas y una experiencia poco amigable, Ataraxia busca eliminar esa fricción mediante una wallet completa, potenciada por un apartado educativo y centrada en que el usario tenga la auto custodia de sus cripto activos y cree su wallet de forma intuitiva, rápida, y segura.

---

## 🌎 El Problema

La mayoría de las wallets actuales están diseñadas para usuarios con conocimientos previos sobre:

* Llaves privadas
* XPUBs
* Descriptores
* Scripts
* Timelocks
* Multisig
* Recovery Keys

Para una persona que recién comienza en Bitcoin, estos conceptos suelen convertirse en una barrera de entrada.

En México y Latinoamérica existe una enorme oportunidad para acercar Bitcoin a nuevos usuarios mediante experiencias más humanas, intuitivas y educativas.

---

## 💡 Nuestra Solución

Ataraxia combina las mejores ideas de proyectos como:

* Sparrow Wallet
* Liana Wallet

y las adapta a una experiencia completamente en español orientada a nuevos usuarios.

Nuestro objetivo es permitir que cualquier persona pueda:

✅ Crear una wallet en minutos.

✅ Comprender los conceptos fundamentales de una wallet

✅ Gestionar su autocustodia de forma sencilla.

✅ Configurar esquemas SingleSig y MultiSig.

✅ Programar mecanismos avanzados de recuperación.

✅ Realizar transferencias de forma intuitiva.

# ✨ Funcionalidades Principales

## 🔑 Creación de Wallet

Ataraxia permite configurar wallets:

### Single Signature

Configuración simplificada para usuarios principiantes.

### Multi Signature

Configuraciones avanzadas para usuarios que desean mayor seguridad.

Soporta:

* 2 de 3
* 3 de 5
* 5 de 7

firmas requeridas.

---

## 🛠️ Gestión de Llaves

Durante la creación de la wallet el usuario puede configurar distintos tipos de acceso:

### Private Key

Llave privada generada automáticamente.

### Magic Word

Sistema experimental de acceso rápido basado en palabras temporales de uso limitado.

### HotWallet Key

Generador de frases semilla compatible con el estándar BIP39.

### XPUB / Watch Only

Importación y exportación de configuraciones compatibles con wallets air-gapped y esquemas de observación.

---

## ⏳ Timelockers y Recovery Keys

Inspirado en Liana Wallet.

Permite crear mecanismos de recuperación avanzados mediante:

### Timelock Absoluto

Fecha fija definida mediante calendario.

Ejemplo:

> Activar recuperación el 7 de junio de 2026.

### Timelock Relativo

Periodo dinámico contado desde una acción determinada.

Ejemplo:

> Activar recuperación 30 días después del último depósito.

---

### Recovery Keys

Permiten:

* Recuperar fondos
* Transferir fondos automáticamente
* Crear sistemas de herencia digital
* Configurar cuentas de respaldo

Además, el usuario puede:

* Crear Recovery Keys
* Editarlas
* Eliminarlas
* Activar o desactivar notificaciones

# ⚡ ARK LINK

## Nuestra propuesta diferenciadora

ARK LINK es una funcionalidad diseñada para realizar transferencias de Bitcoin de forma inmediata entre dos dispositivos cercanos.

Inspirado en la experiencia de pagos digitales modernos.

### Flujo

1. Usuario A genera un Ark Link.
2. Se crea un QR temporal.
3. Usuario B lo escanea.
4. La transferencia se realiza instantáneamente.
5. Ambos usuarios reciben confirmación.

Objetivo:

Convertir Bitcoin en una experiencia cotidiana tan sencilla como compartir un mensaje.

---

# 💰 Modelo de Negocio

Ataraxia plantea un modelo basado en:

### Comisión por transacción

3% por cada operación realizada dentro del ecosistema Ark Link.
